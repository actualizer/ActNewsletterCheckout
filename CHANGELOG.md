# 1.0.13

- Changed: from Shopware 6.7.9.0 on, the newsletter subscription at checkout uses Shopware's current method instead of the deprecated one. This avoids deprecation notices and keeps the subscription working when the Shopware 6.8 feature flag is enabled.

# 1.0.12

- Fixed: on Shopware 6.7.0 to 6.7.8 the newsletter subscription at checkout failed, because a method the plugin used only exists from 6.7.9.0 on.

# 1.0.11

- Tested with Shopware 6.7.16.0.
- Added a changelog in English and German.
